# ShopScope Lite — Session 2 (solution)

The finished app for **Session 2 — Modern JavaScript (ES6+)** of the JS & TS Foundations track at Deesha Tech Academy.

Search by title or brand, category chips generated from a `Set` (with counts from a `Map`), five sort orders that
never mutate the original list, a live stats panel built with `reduce`, and the Session 1 wishlist, now kept in one
`state` object that `update()` turns into the whole page. The wishlist survives a reload (`localStorage`).

```bash
npm install
npm run dev      # http://localhost:5173
```

Node 22 or newer. No frameworks: plain JavaScript, ES modules and Vite.
