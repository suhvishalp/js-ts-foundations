# ShopScope Lite — Session 2 (starter)

The starting point for **Session 2 — Modern JavaScript (ES6+)** of the JS & TS Foundations track at Deesha Tech Academy.
It continues from Session 1's finished product page.

```bash
npm install
npm run dev      # http://localhost:5173
```

Node 22 or newer. The page renders straight away: sixteen product cards, a working wishlist, and a toolbar and stats
panel that do nothing yet. Sixteen `TODO(lab-2.x)` markers show where today's code goes. Search for `TODO(lab-2.` to
find them all, and follow the session guide (`../README.md`) lab by lab.
