# Session 4 starter — ShopScope Lite, live catalogue

The Session 3 app (cards, cart store, render helpers) with the products moved
to the network, and the network layer stubbed. The page builds and renders,
but every request returns an empty default, so the grid shows an empty state.

```bash
npm install
npm run dev        # http://localhost:5173
```

Sixteen markers, `TODO(lab-4.x)` style, show where each lab's code goes.
Search for `TODO(lab-` in your editor. The session guide is `../README.md`.
