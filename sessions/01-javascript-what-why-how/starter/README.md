# ShopScope Lite — Session 1 (starter)

The starting point for **Session 1 — JavaScript: What, Why & How** of the JS & TS Foundations track at Deesha Tech Academy.

```bash
npm install
npm run dev      # http://localhost:5173
```

Node 22 or newer. The page renders straight away: one product card and a JS Playground. Twelve
`TODO(lab-1.x)` markers show where today's code goes. Search for `TODO(lab-1.` to find them all, and
follow the session guide (`../README.md`) lab by lab.
