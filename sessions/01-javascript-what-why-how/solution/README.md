# ShopScope Lite — Session 1 (solution)

The finished app for **Session 1 — JavaScript: What, Why & How** of the JS & TS Foundations track at Deesha Tech Academy.

A product grid rendered from `src/data/products.js` with `createElement`, stock badges, a wishlist driven by one
delegated click listener, and a JS Playground that runs the classic misconception experiments live.

```bash
npm install
npm run dev      # http://localhost:5173
```

Node 22 or newer. No frameworks: plain JavaScript and Vite.
