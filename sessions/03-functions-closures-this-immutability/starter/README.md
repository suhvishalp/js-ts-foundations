# ShopScope Lite — cart & store (Session 3 starter)

The starting point for **Session 3 — Functions, Closures, `this` & Immutability** of
*JavaScript & TypeScript Foundations* (Deesha Tech Academy).

It is Session 2's finished catalogue (search, category chips, sort, stats) plus
the cart's skeleton. It builds and renders; the behaviour goes where the
`TODO(lab-3.x)` markers are. Search for `TODO(lab-3` to find them all.

```bash
npm install
npm run dev      # http://localhost:5173
```

Node 22 or newer. Follow the session guide in `../README.md`.
