Clear the fog first

Five things people get wrong about JavaScript

JavaScript is a lighter version of Java.

They are unrelated languages. The name was a 1995 marketing decision.

JavaScript is only for small scripts on web pages.

It runs servers, mobile apps, desktop apps like VS Code, edge functions and AI tooling.

Single-threaded means slow and blocking.

The event loop lets one thread handle thousands of network requests without waiting on any of them.

const means the value can't change.

The binding is constant. The object it points to can still change, which is why immutability matters in React.

TypeScript checks your data at runtime.

Types are erased when the code compiles. TypeScript protects you while you write, so you still validate data from the network.
